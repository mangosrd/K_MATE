## 지원 포맷
- `.mp3` 권장 (iOS/Android/Web 모두 호환)
- `.ogg` 도 사용 가능하나 iOS Safari 미지원
- 파일 크기: 곡당 3~5MB 이하 권장 (스트리밍 없이 전체 로드)
